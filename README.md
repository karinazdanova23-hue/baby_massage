# Дневник массажиста (baby_massage)

Приложение для записи клиентов, доходов и задач. Данные хранятся на сервере (S3 Timeweb), заходят двое: Карина и муж, у каждого свой пароль.

## Переменные окружения (Timeweb → приложение → Переменные)

| Переменная | Что это |
|---|---|
| APP_PASSWORD_KARINA | пароль Карины |
| APP_PASSWORD_HUSBAND | пароль мужа (если нужен один пароль на двоих, задайте в обеих одно и то же) |
| SESSION_SECRET | любая длинная случайная строка (чтобы входы не слетали при перезапуске) |
| S3_ENDPOINT | https://s3.twcstorage.ru |
| S3_REGION | ru-1 |
| S3_BUCKET | имя бакета |
| S3_ACCESS_KEY / S3_SECRET_KEY | ключи доступа к бакету |
| RESEND_API_KEY | ключ Resend (для ежедневной копии на почту) |
| BACKUP_EMAIL | куда присылать копию |

Без S3 данные пишутся в локальную папку и пропадут при пересборке, поэтому S3 обязателен.

## Обновление приложения
Заменить файл `public/index.html` в репозитории. Timeweb пересоберёт приложение сам.
